# HTTP Status-Code Classes Resources

## Knowledge

- [MDN: HTTP response status codes](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status)
  The canonical practical reference — all five classes and every common code with usage notes. Use for: what any specific code means and when it's sent.
- [RFC 9110: HTTP Semantics — §15 Status Codes](https://www.rfc-editor.org/rfc/rfc9110#name-status-codes)
  The authoritative specification. Use for: settling arguments about what a code *officially* means.

## Wisdom (Communities)

- [Stack Overflow — `http-status-codes` tag](https://stackoverflow.com/questions/tagged/http-status-codes)
  Real-world disputes about which code applies. Use for: judgment calls the spec leaves open (e.g. 400 vs 422 for validation errors).
